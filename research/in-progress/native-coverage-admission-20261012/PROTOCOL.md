# Native coverage population admission

This follow-up consumes the unchanged version-2 PHerc0814 reservation. It is
development data qualification, not inference, a learning experiment, paid
compute, or fresh evaluation. Completed studies remain immutable. No payloads
from PHerc0175 A/B or PHerc1203 may be opened; PHerc0841 and the whole PHerc0009
family remain excluded from new training.

## Added stream

Keep all 11,887 previously reserved candidates, including the 2,886 restricted
members, in the accounting. Do not change block hashes, geometry eligibility,
coordinates, or per-segment definitions. For every candidate:

1. Require every intersecting native 28×128×128 source chunk to be present with
   the declared byte length and format. Acquire the complete chunks, pin actual
   SHA256, ETag and length, and retain every failed source. The first retrieval
   binds a current object; it is not a historical publisher snapshot certificate.
   Known teacher-object ETags are fixed from the prior header intake and must
   match. Missing objects are failures, never all-zero CT replacements.
2. Decode only the TIFF tiles that can affect the candidate outputs under the
   same global INTER_AREA resize. Compare explicit deflate and official TIFF
   decodes. Preserve the global source and destination shapes. Reproduce the
   seven saved smoke crops as an implementation control, separately from this
   reserved candidate population. Do not change coordinates to improve agreement.
3. Use the already declared teacher thresholds: ≥128 positive, ≤64 negative,
   intermediate values ignored. Native centre-plane CT >0 is required for
   supervision. A technical training candidate needs at least 1,024 supervised
   pixels (6.25% of a 128-square); this mask-support minimum follows the earlier
   native-reference intake. The rule applies identically to A and B and is fixed
   before population values. There is no positive-class admission requirement.
4. Report all positive/negative/unknown counts, all one-class patches, input
   nonzero support by depth, failures, and exact overlap on the native UV grid.
   Supervision outside the valid native input is ignored. Nonzero CT is only a
   storage/material-support rule, not a physical ink or sheet-identity label.

Weak teachers remain separate from direct native annotations. Mechanical
resizing does not certify fine/native registration. Do not use teacher agreement
as an independent improvement endpoint. Geometry/UV overlap summaries do not
establish independent physical subjects or distinct sheet area.

Freeze the exact union of requested chunks/teacher ranges before acquisition.
Reuse only byte-verified identical retained inputs. Write a receipt after each
object so interrupted acquisition resumes without replacement or changed inputs.
At most three attempts for transient 429/5xx/connection failures are allowed;
identity/decode failures stop. Report retries and actual body bytes. Missing
404 responses are recorded once. No request may exceed its declared body size.
The maximum planned new payload is 6.3 GiB, with an 8 GiB bound including retry
bodies. Use at most sixteen concurrent reads. No paid runtime is involved.

## Original stream and later decisions

Use exactly the five proposed native PHerc0139 annotation sources, w035, w039,
w040, w041 and w044. Inspect their declared supervision before newly acquired
label values. Enumerate 128-square cores at stride 96 contained in the native
canvas with at least 1,024 supervised pixels; no class filter. Earlier exposed
source values remain development evidence. Preserve native-coordinate ancestry,
ignore all outside-mask labels and retain known aliases (including w044/w028).
Bind native input chunks and report CT-supported class counts before admitting
the stream. Existing complete arrays/chunks may be reused after hash checks.
These new training roles do not amend prior winding folds or reevaluate them.

After both population tables exist, assess whether a meaningful coverage
contrast survives. Freeze source quotas, augmentation schedules, loss weights,
initializer and adequate optimization exposure before training. Report class
and support differences under the intended equal-segment sampler; a subsequent
balancing/control rule must be explicit and applied to both arms before any
model-performance feedback. If a parent lacks support, stop this design rather
than silently drop it or move the narrow blocks. Population admission alone
does not qualify evaluation detail/negative references or authorize GPU rental.

The next paid proposal, if justified, must include the actual dataset and CUDA
workload, current pricing, artifact delivery, independent shutdown and the £10
total first-pilot cap. Obtain approval before paid work. Short CPU mechanics
results are not learning-power gates.
