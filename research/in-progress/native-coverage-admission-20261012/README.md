# Population intake: partial, blocked by outbound transport

12 October 2026. The intended comparison is unchanged, but **the complete
training population could not be admitted**. The environment's outbound proxy
began returning HTTP 503 before source response headers. No model inference,
training, paid resource or new evaluation was run. Transport failures are kept
separate from confirmed missing data and from scientific rejection.

## What completed

The [frozen protocol](PROTOCOL.md) retains all 11,887 PHerc0814 candidates and
their 2,886 restricted-arm members. Its exact source union is 13,010 complete
native CT chunks plus 4,560 required teacher tiles, including the prior fixed
smoke controls: **6,490,436,236 planned bytes** before reuse. Every candidate in
both arms requires the same input contract and at least 1,024 supervised pixels.
There is no positive-ink admission requirement or replacement of failed regions.

All five fixed original PHerc0139 annotation sources were acquired or reused,
bound to their native metadata, and decoded through both official Zarr and the
retained independent shard/Blosc implementation. Supervision was inspected and
the stride-96 grid frozen before newly acquired label values. The source masks
cover **5,023,011 pixels**; **1,914,370** stored positive pixels lie inside them,
and **99,289** lie outside and are ignored. These are native annotation values,
not independently authenticated ink.

The 481 readable candidates all retain at least 1,024 supervised pixels after

these are not unique physical-area totals. There are 122 patches with no

No unknown source is given an all-zero CT substitute or scored as a negative.

## What the network failure prevented

The added-stream cache contains **905 CT chunks and 16 teacher-tile ranges**,
921 objects totalling 417,055,135 bytes. The original stream has 400 verified CT
chunks totalling 183,500,800 bytes. These are recoverable partial caches, not
complete populations. **16,649 added requests and 381 original CT requests
remain unresolved or unattempted.** No newly requested source was confirmed
missing; HTTP 503 is not evidence of an absent S3 object.

Only three added candidates currently have every required CT and teacher byte
range available. Their population supervision was not promoted into a smaller
substitute experiment. The coverage/class comparison cannot be decided from
this availability-selected subset. The previously missing smoke-centre chunk
remains a distinct historical result; it was not swapped for another location.

The first acquisition saved 843 receipts before repeated 503 errors. A recorded
four-reader recovery saved another 50. A subsequent bounded availability pass
reused prior smoke inputs, collected seven more CT objects, and stopped after
the declared consecutive-error limit. Remaining unattempted requests are listed
separately from observed errors. Original local reuse completed even during the
outage. Source URLs, validators, reservations and eligibility did not change.

The diagnostic response was:

> upstream connect error or disconnect/reset before headers … remote connection
> failure … immediate connect error: Invalid argument …
> envoy://cloudflare_https_tunnel/

It occurred through both the standard and documented regional S3 endpoints;
HEAD and a bounded full-chunk range also failed. Inherited proxy routing and TLS
verification were preserved. The environment status tool still reported a
connected/running instance; that did not establish working S3 transport. This
is an observed proxy error, not a diagnosis of the provider's internal cause.

All transport changes are explicit: `TRANSPORT_PLAN.json` lowers concurrency;
`AVAILABILITY_PASS_PLAN.json` records one attempt at unaffected requests, a
consecutive-error stop, and exclusion of the already diagnosed failed request
from another retry. The original protocol and requests remain unchanged.
Initial and recovery logs/failure records are preserved. Early fail-fast receipts
do not retain every failed worker's request ID, so the record does not claim
a complete per-attempt network audit. Successful source byte identities and the
remaining request list are retained exactly.

## Decision and resumption

This is an **operational pause**, not evidence for or against broader native
learning. Do not change the eight added segments, shrink the original stream to
three windings, redraw A's blocks, reinterpret unavailable data as blank, or
launch GPU training on the current partial cache.

When S3 transport works again, resume the two unchanged request manifests,
reuse verified receipts, and fetch only unresolved sources. Then qualify the
entire teacher/native population, report per-segment class/support exposure
under the intended equal-segment sampler, and recompute the admitted physical
context contrast. Preserve this partial qualification as a dated record and
write the complete qualification to a new output directory.

Only then freeze the initializer, loss coefficients, exact draws, adequate
training budget, supported development endpoints and concrete GPU proposal.
The practical improvement/retention/negative-control criteria are unchanged.
New paid compute needs approval and retains the £10 total first-pilot cap.
The PHerc0175 A/B and PHerc1203 reserve remains unopened, and PHerc0841/PHerc0009
remain excluded from new training. Geometry reference adjudication remains a
separate open dependency; no geometry was selected using an ink response.

See [PORTABILITY.md](PORTABILITY.md) for the private partial-source checkpoint,
offline verification and the exact safe acquisition-resume procedure. No spare
VM assignment or Actions workflow was launched for this step.
