# Fixed-state comparison implementation

This package prepares the frozen sixteenth design without executing scientific inference. The same seed42 baseline and thirteenth A_preserve/B_preserve states are retained. Their exact weight, semantic-state, fourteenth cutoff and source identities are recorded in SOURCE_PINS.json. No normalization, model, orientation or checkpoint selection is proposed.

The two-phase controller first predicts only the two Frag3 calibration contexts, in baseline/A/B order. Each worker uses the unchanged seventh negative-only conservative 95% specificity selector on the literal fifteenth primary negatives; its new cutoff is the maximum of the two regional cutoffs. All three successful calibration receipts are verified before an atomic locks-ready file is published. Only then can separately constructed workers predict the four Frag1/2 contexts. Launch/completion timestamps and barrier hashes document this ordering; a missing, unrelated, nonfinite or incomplete lock stops execution.

Each input is exactly float32[17,384,384], produced by uint32 sums over 27 source uint16 values, one float64 division by 6939 and one float32 conversion. The unchanged reference adapter uses layer_start 0, forward depth, 25 row-major 128² tiles at stride 64, the retained full-patch robust MAD normalizer and sigmoid/Hann probability blending. Masks never enter normalization. Every literal primary pixel must be evaluated with a finite score in [0,1]; support is never reduced to rescue a result. Raw tile logits, blended scores, evaluated masks and normalized-input fingerprints are retained.

There are 450 tile forwards, six final-role worker constructions and ten strict state loads: six initializer loads plus four candidate-state replacements. Every load uses weights_only=True, exact tensor keys/shapes/dtypes, finite values, verified storage aliases and semantic-state hashes. Models stay on CPU in FP32 eval/inference mode with absent gradients and unchanged state. There is no training, optimizer, checkpoint output, retry or network access.

The original operating cutoffs are explicitly the retained fourteenth development cutoffs: baseline 0.7558947205543518, A 0.7450202703475952 and B 0.7422624826431274. They remain unchanged beside each model’s Frag3-only cutoff. The analyzer reports exact confusions, sensitivity, specificity, precision, F1, predicted-positive fraction, balanced accuracy, ROC AUC, AP and primary-label prevalence. Undefined precision remains undefined in every containing macro. Fragment means give their two contexts equal weight; the Paris2 summary gives its two fragment means equal weight. Exact per-context 20*FP<=Nnegative and all-four checks describe specificity transfer, without a model-promotion criterion.

Retained eleventh execution took 62.202 seconds for 500 forwards across five worker constructions; fourteenth took 31.651 seconds for 118 forwards across two constructions. These are source evidence for feasibility, not new measurements or a promised completion time. The frozen caps are 120 seconds wall/360 seconds CPU per phase worker, 600 seconds aggregate, four threads, 3 GiB peak-RSS acceptance, 12 GiB address space and 96 MiB run outputs. Logits/scores/evaluated masks require approximately 41 MiB before small JSON/log receipts; normalized inputs are fingerprinted rather than duplicated.

The ready builder requires a source-bound GO receipt for the sealed code and root design, plus an independent CT PASS tied to the exact descriptor and typed all_CT_arrays_exact=true. A status string, nonempty review list or label-only preparation cannot substitute for those gates. CT acquisition and byte-exact reconstruction remain separate owners’ prerequisites. The draft plan stays ready_for_execution=false until root supplies that evidence.

## Interfaces

prepare_plan.py accepts --descriptor, --research-design, --source-go, --ct-verification, repeatable --review, --output-dir and root-only --ready. Its descriptor has status pooled_reference_complete_no_inference, the exact preprocessing contract and six cases. Each case supplies id, native_bbox_yxhw and the canonical arrays surface/labels/primary_mask/known_mask/surface_mask; the four label/support records must match fifteenth bytes exactly. Array records contain path, SHA256 and size_bytes (byte_length/bytes are accepted only if consistent).

run_comparison.py accepts --plan and --output-dir. --preflight checks arrays without models; only root executes it after the input contract is ready. The controller owns all scientific workers. analyze_comparison.py accepts --plan, --results and a fresh --output-dir and scores completed outputs without fitting or models. check_fixtures.py accepts a fresh --output-dir and uses only artificial NumPy arrays and JSON records.

All six contexts, three states, both operating rules and unfavorable outcomes are retained. This is supplied-reference agreement on one evaluation parent, with inspected labels and unknown upstream exposure; it is not authenticated ink, independent population accuracy or a reading.
