This package prepares and executes the root-reviewed eighth CPU pilot. All real model execution belongs to the root. The existing `draft-plan/` is preserved as a pre-review, not-ready artifact; its source pins precede the final review changes.

After independent source/code review, the root runs `prepare_plan.py --fresh-descriptor ../data-design/acquisition/fresh-descriptor.json --data-review ../data-review/DATA_REVIEW.md --data-review ../data-review/result/DATA_VERIFICATION.json --data-review ../data-review/review-manifest.json --output-dir final-plan --ready` from this directory with the existing lab Python. It binds the frozen code, protocol, decisions, source plan, source/teacher maps, checks and source review; `final-plan` must not already exist.

Then run `run_experiment.py --plan final-plan/training-plan.json --output-dir run` followed by `analyze_experiment.py --plan final-plan/training-plan.json --run-dir run --output-dir analysis`. Each destination must be new. The controller runs the frozen baseline and A/B/C sequentially, with no retries. Each student trains, writes development maps and both threshold locks, then predicts fresh contexts. Final-only raw state dictionaries receive safe strict roundtrip validation before predictions. Source/code identities are checked again after execution and analysis.

`check_fixtures.py` uses synthetic logits only. Its fixtures verify independent masked BCE means/gradients, four-group anchoring, unknown output-logit gradients, all D4 transforms, deterministic cycles and conservative threshold ties. It makes no model call. Image context outside label participation remains available to the network. Supplied annotation agreement and teacher imitation remain developmental diagnostics; no geometry, historical holdout, authenticated ink, significance or reading claim follows from this pilot.
