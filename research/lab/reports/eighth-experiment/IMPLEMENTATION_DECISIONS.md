# Fixed implementation decisions

Accepted by the lead before any adaptation or fresh inference, 8 October 2026.

Use AdamW with learning rate 0.0001, betas (0.9, 0.999), epsilon 1e-8, weight decay zero, no scheduler and global gradient-norm clipping at 1.0. Use exactly 32 steps, batch size two, FP32, four CPU threads and deterministic algorithms in all arms. Initialize the optimizer afresh and load exactly the same original seed42 bytes for every arm. This single conservative continuation setting is fixed without a learning-rate search. The preceding synthetic SGD check establishes mechanics only; it does not validate Adam memory or throughput.

The implementation agent recommended AdamW because layer-dependent gradient scales could make 32 SGD steps nearly uninformative. Adam's two moments add approximately 276 MB for this model. Measure actual peak memory and stop on limits rather than infer a fit from the synthetic check. Per training/evaluation worker: 120 seconds wall time, 360 CPU seconds, 12 GiB hard address-space limit and 4 GiB peak-RSS acceptance. All final checkpoints, predictions, logs and analysis must fit 700 MiB. Preserve failure evidence; no automatic retries or post-result hyperparameter changes.

Each update includes one eligible patch from each PHerc0139 region. Manual eligibility and tile selection use supplied manual-participation counts, never teacher predictions. Teacher finite/evaluated support intersects pseudo participation only; teacher disagreement does not change manual labels. Freeze the complete 32-step tile/augmentation schedule and reuse it byte-for-byte across arms. Record per-step manual/pseudo class counts, group counts, loss terms, gradient norm and timing. Save each fixed final state only, with initialization, plan and schedule identity. No early checkpoint selection.

The published initializer and teacher used BCE label smoothing 0.5 (targets 0.25/0.75). This pilot intentionally uses unsmoothed 0/1 targets in every arm. Thus A versus frozen seed42 includes both continuation and a common target-smoothing change. B versus C remains matched for that change. Score-scale movement alone is not evidence that regional balancing works; calibration is recomputed from fixed development support for every model. The pilot does not reproduce the authors' full training recipe.

Compute calibration from the three fixed development regions and write its threshold receipt before inference on the fresh contexts. The frozen baseline reuses its existing development maps; it needs new inference only on the fresh regions. Adapted models use the identical reference inference path. Source arrays, masks and raw scores remain separate. No evaluation pixels enter a gradient update.

The primary calibration rule deliberately uses the maximum of three per-region 95%-specificity cutoffs. A weighted pooled rule was considered but would permit one development region to fail the target while its aggregate passed. The maximum rule may cost sensitivity and may coincide with the original threshold; both are legitimate outcomes to retain. It establishes no prospective specificity guarantee on fresh regions.

For a precise descriptive decision, compute the protocol's C-versus-B screen separately from incremental value against A and frozen seed42. Apply the same bounds to each comparison: C specificity at least 0.95 in each fresh context, equal-context sensitivity gain at least 0.02, no context sensitivity loss exceeding 0.02, no context AUC loss exceeding 0.01 and no context AP loss exceeding 0.02. A "promising candidate beyond the cheaper controls" requires all three comparisons to pass. These are screening margins, not statistical significance or an adoption guarantee. Retain all continuous differences even when a margin fails.

Review responsibilities: the lead performs the high-level scientific review per the user's request; data and numerical checks are delegated independently. No separate Astra strategy review is required. Actual source acquisition and execution remain root-owned after immutable code/input plans are delivered.
