# Independent technical review before regional diagnostic reads

Prepared from retained sixteenth results/design and fifteenth source/benchmark contracts. This is a narrow software/numerical review, not a replacement scientific strategy. No CT, label/support, score or checkpoint array has been decoded for this review; no network request or transform search has been made. The scientific lead must freeze the concrete diagnostic protocol before corresponding real numeric reads.

## What the retained evidence can establish

A successful coordinate audit establishes agreement with the declared released raster and the retained adapter: orientation 1, YX indexing, native XYWH versus YXHW, coarse center origin+1+3i, and depth centers 8+3j for j=0..16 with j=8 centered on declared plane 32. It does not authenticate that the released label depicts the same physical point in the CT or that declared depth increases in an anatomically known direction.

The fifteenth label path samples native labels/surface/known status at the same coarse center. Known status requires a complete, constant-label 33-square inside the surface; primary support additionally excludes a 32-coarse-pixel context border. These exclusions are part of a deterministic supplied-label benchmark. They do not bound physical registration error, and unknown support cannot silently become negative support.

The sixteenth byte-exact CT reconstruction already addresses raw endian handling, varying strip offsets, pooling overflow and axes. Repeating a fixed, analytically chosen sentinel reconstruction can guard accidental phase-seventeen indexing drift. It should be reported as software provenance, not new physical alignment evidence. Whole-array source hashes, dtype/shape and finite/range invariants bind the actual diagnostic inputs.

CT intensity profiles, adjacent-depth changes, variance or label-stratified means can reveal differences between the fixed regional inputs. Such association is compatible with density/fiber structure, local surface geometry, flattening artifacts, acquisition contrast or ink. Intensity maxima or label associations alone do not localize the ink plane, establish optical registration, orient the surface normal or identify the cause of model failure. The arithmetic depth offset (8+3j-32)*3.24 micrometres is metadata-derived, not a measured displacement normal to a verified surface.

Saved predictions permit fixed-support score/confusion summaries and descriptive dependence on fixed CT summaries. They cannot supply an independent alignment reference: fitting a shift, flip, inversion, cutoff or depth to labels/predictions would be evaluation-informed optimization. A high association after a search would also conflate label, model and transform errors. The current audit should retain all six contexts and every frozen depth, with no best-depth/transform selection or exclusion after viewing results.

## Narrow discriminating checks

1. Compare each context's declared source XYWH/YXHW and all four coarse corners/center mapping across benchmark, CT pooling and prediction plans. Use asymmetric coordinate fixtures because square shapes hide transposes.
2. Verify labels, surface, known and primary arrays are literal fifteenth objects; check binary values, primary subset of known and surface, class/support count identities, and the exact primary border rule. This diagnoses support mistakes, not annotation truth.
3. Bind CT and scores to named context IDs and immutable file hashes. Assert one expected shape/dtype per input; reject nonfinite values and score values outside [0,1]. Check exact expected model/context cardinality so missing or duplicated regions cannot disappear from a summary.
4. Check depth-index arithmetic independently, including first, center and last planes. If raw sentinels are included, freeze their indices beforehand and reconstruct the exact 27-voxel integer sum divided by 6939, followed by one float32 cast. No peak-selected sentinel.
5. Recompute fixed-cutoff confusion counts and reconcile with saved sixteenth counts. Use score converted to float64 >= the unchanged cutoff; preserve zero-prediction and zero-support undefined outcomes explicitly. New support groups are diagnostics only and must not replace the benchmark.

A failure of these identity checks implicates an implementation/contract mismatch. Passing them narrows that category but leaves physical registration, depth convention and representation unresolved. Physical correction needs independent optical landmarks/registration provenance or PPM/renderer geometry evidence, with residuals measured independently of model score improvement.

## Independent numerical verification requirements

Use a separate implementation that imports no author numerical helper, Torch or checkpoint loader. Bind source/plan/input hashes in a receipt before numeric reconstruction. Use explicit float64 accumulation and population standard deviation if dispersion is selected; define quantile interpolation, histogram bin closures, mask scopes and zero-denominator behavior in the frozen protocol.

Meaningful synthetic fixtures should cover asymmetric non-square coordinate and depth ramps, constant and empty groups, singleton groups, tied values, exact quantile interpolation, histogram boundary values including the terminal edge, finite/range rejection, population versus sample variance, and a label/support case in which outside support would change the answer. Pearson or analogous association requires constant-vector behavior fixed in advance; no significance claim from spatially dependent pixels.

For an actual authorized run, independently reconstruct all primary JSON statistics from immutable arrays, including every selected depth/model/support group. Compare exact integer/count/hash fields and use explicit absolute/relative tolerances for floating reductions only. Small direct scalar-loop expectations should validate the independent vectorized implementation first. A plot is a presentation, not a numeric oracle; verify its source table and fixed axes/scale separately.

No positive conclusion about authenticated ink, text, generalization or improved model follows from this diagnostic arithmetic. The original sixteenth results and limits remain in force.
