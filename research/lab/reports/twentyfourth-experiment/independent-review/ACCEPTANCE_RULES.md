# Independent paired depth-order acceptance

The intervention is the exact FP32 depth permutation of each original normalized input. The unchanged adapter reads and normalizes the original patch; capture verifies its original fingerprint, flips axis 2 into contiguous storage, verifies the canonical reversed fingerprint, and only then calls the model. Original and reversed inputs must remain unchanged afterward. Raw-reversed renormalization is not the execution recipe.

Prospective fixtures demonstrate why that distinction matters: a sparse synthetic patch with MAD fallback gives different FP32 normalization after raw reversal (`7.152557373046875e-7` maximum difference). Constant and structured fixtures verify identity, signed-zero preservation and exact plane permutation. This observation was recorded before any new model output; it does not diagnose a physical orientation error.

The checker reuses pinned, sealed phase23 independent tied-group ranking/support arithmetic and phase22 independent normalization/sigmoid/Hann/state helpers. It checks both original/reversed fingerprints on all 150 unique inputs for each model, all fixed primary masks and classes, all 300 model calls, and each model's 508 named value hashes and 244 alias pairs before/after. Seed42 is independently decoded only with `torch.load(weights_only=True,map_location='cpu')` after exact artifact verification; its original config/step and legacy semantic hash must match. Native is independently inspected through safetensors NumPy and compared with the prior native state identity. No checker model construction or forward is allowed.

Raw ROC-AUC/AP, reverse-minus-forward changes, native-minus-seed42 differences of changes, and model-specific probability drift are independently reconstructed for all contexts. Paris1 and Paris2 means use their fixed two/four context groups. Metric tolerance remains `1e-12`; probability arithmetic tolerance remains `2e-6 + 2e-6*abs(reference)`. All input/state/source/schedule/support identities are exact. Saved forward controls are pinned and independently reconstructed, not replayed. No quantized, threshold, direction-choice, ensemble or performance gate is added.

Fresh fixtures cover safe generated-state decoding, wrong model/checkpoint/semantic identities, swapped forward references, count/shape/sigmoid/coverage rejection, input ownership/fingerprints, parent averaging and difference-of-changes signs. Twenty-one tests pass, in addition to the three prospective permutation cases and previously sealed ranking tests. While adding parent-summary fixtures, a test method was temporarily placed in the wrong fixture class; its failing log and original test source are retained. Correcting its placement did not change implementation arithmetic, tolerances or scientific inputs. All corrections occurred before actual model outputs.

Source and resource bindings are verified against the root protocol. PASS denotes verified paired execution and calculations on reused development contexts; it does not select an input direction or prove anatomical correctness, independent accuracy or causal training benefits.
