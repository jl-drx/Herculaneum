# Next experiment: PHerc343 native-coarse positive-control reproduction

**Question:** Can our pinned rendering and inference path reproduce the published PHerc343 source-linked ink pattern at the same8.64 µm / 116 keV acquisition setting as PHerc0800? This directly tests whether the adopted pipeline has a positive example in the target acquisition domain before interpreting another dark target result or choosing a training treatment.

**Baseline:** the published PHerc343 meshes, d=+1 reading-side maps and final image at repository `e8370f1f88a211166056df62ea6fcfffe4a1063e`. Mesh concatenation is already reproduced exactly. Use the pinned dense_native16k, official seed42/43 75k, and Hecate9.6 µm artifacts. Preserve individual model outputs. Reproduce the author ensemble for comparison, without fitting new weights, contrasts or depth choices. The public sidecar contains the fixed per-model means/SDs and ensemble display stretch; reuse these for image reproduction, not as model calibration for PHerc0800.

**Execution:** first verify the 66-plane VC3D render's half-voxel centre and sampling using the exact published mesh and pinned renderer. Start with source-coordinate checks and a fixed crop for implementation debugging, then reproduce the complete published image extent at the fixed d=+1 endpoint. This is a reproduction target selected because it contains a known published result, not an untouched benchmark. Preserve the original/padded tile origins and ownership merge; arbitrary recropping or a new tile phase is not equivalent. **Reference and supervision:** no training. The final published image and hash-pinned geometry are the reproduction reference. Letter boxes are location metadata, not pixel labels. A clipped, composited PNG cannot recover those maps. No trusted AP target is manufactured from the image. The author-reported papyrologist reading remains a separate provenance claim until its review record is obtained.

**Stopping criterion:** stop for failed source identity, renderer/sampling mismatch, unsupported regions or inconsistent tile-phase mapping. Resolve implementation faults before treating a negative image as a scientific failure. Finish the fixed d=+1 comparison without choosing a better-looking depth or checkpoint. If the published strokes fail to recur despite a verified render and correct preprocessing, report failure to reproduce and identify which single-model contribution differs; do not port an unqualified pipeline and label PHerc0800 blank. A successful source-linked pattern reproduction, with differences and context explicitly documented, justifies the target transfer. Exact image/CT equality is a separate technical criterion where the requisite full inputs and display operations are reproduced.

**Decision-changing result:** if this matched-acquisition positive control works while a prospectively fixed PHerc0800 field remains unrecovered under the same released models, inadequate generic inference implementation becomes less plausible; geometry, local signal, material appearance and domain transfer become the research targets. If the positive control fails, another PHerc0800 null is not interpretable and training scale is premature.
