# Reuse this study elsewhere

The private GitHub research branch preserves selected protocols, code, results, source snapshots, compact figures and source identities from this study. It does not contain the large checkpoint files, CT chunks, training arrays or prediction arrays. The full retained-state manifest remains in the cloud lab and is verified against an external SHA256 anchor in the environment startup instructions. Saving those instructions does not publish a filesystem snapshot or upload bulk artifacts to R2.

The continuation inherits phase44's public input release. `research/tools/materialize_phase44.py` and phase44's pinned range plan can reconstruct the nine native model-input arrays; the earlier cached-range recovery was verified. This study's successful exact 2,048-step training replay adds evidence for deterministic model recovery in this runtime. It does not demonstrate a complete fresh-machine replay. New model/optimizer/RNG checkpoints exist at2,048,4,096,8,192; `NATIVE_CHECKPOINT_TENSOR_HASHES.json` fingerprints every saved model tensor without treating serializer-container bytes as model identity.

Research scripts preserve original absolute paths and read-only dependencies on earlier phase directories. Reconstruct the documented tree or adapt paths in a new work directory, with new receipts. Do not run write-once workers against sealed original outputs. `resume_panel.py` is an operational record containing completed process IDs, not a reusable startup command.

The released-checkpoint panel uses the official HuggingFace revision in `checkpoint-panel/ACQUISITION_PLAN.json`. It can recover both seeds at 60k and 75k by full SHA256 and length; the source model factory, normalizer, source arrays, masks and tile placement remain those pinned in phase37. Four checkpoints on the same eight reused regions are not four independent experiments or an untouched test set.

The PHerc0800 geometry diagnostic retains sparse sample indices, the three exact source meshes, 71 compressed M7 chunks, all 243 selected node statuses, and independent reconstruction code. `geometry/PLAN.json` supplies all public chunk URLs and checksums. Reacquiring mutable public objects requires checking their captured hashes, not silently accepting newer bytes. Missing M7 data must remain unknown.

PHerc343 source code and small metadata are pinned to Git commit `e8370f1f88a211166056df62ea6fcfffe4a1063e`; the source meshes and published 8.8 MB PNG are retained locally and recoverable from that commit. The exact concatenation replay is recorded separately from unperformed CT/render/ink reproduction. The author code is MIT and derivative scan geometry/images are CC BY-NC 4.0. The Hecate9.6 µm artifact has only been identified, not downloaded or executed. Its loader, card and requirements are pinned in the source evidence.

CPU monetary spend is unrestricted. The measured runtime quota is four CPU cores. Avoid concurrent four-thread Torch workers; this study records a state-preserving pause/resume after severe contention. Future runs should schedule model workers sequentially or prospectively qualify a different thread allocation. Do not infer a GPU runtime from the CPU elapsed time.

GPU admission now depends on a concrete experiment, suitable data/reference, measured runtime and a complete cost/shutdown/artifact-delivery plan. It no longer universally requires a CPU AP gain. The £10 total first-pilot cap remains. No credential values are in this export; R2/Runpod runtime delivery is still pending and no paid resource was created here.
