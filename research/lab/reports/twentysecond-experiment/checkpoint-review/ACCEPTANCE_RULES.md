# Independent artifact acceptance, frozen before tensor values

Stage 1 has exactly one artifact identity: 272,767,904 bytes, SHA256 d3d95dc41dcb24ed76b84b5e12ca5dae25d7fb34edf1dfbb93e0186f91e6fc6d. The retained 8-byte prefix and 66,192-byte header must match their phase 21 hashes exactly. The checker hashes the entire file and verifies the prefix, header, file extent and exact retained schema before importing the safetensors reader or obtaining any tensor. It hashes the file again after checking to reject concurrent change.

Independent implementation: `safetensors.safe_open(..., framework='numpy')`, installed version 0.8.0. This checker imports no author qualification code. Additional independent JSON validation rejects duplicate keys at all levels, nonstandard numeric constants, metadata not present in the exact retained header, wrong names, fields, dtypes, shapes, boolean/negative offsets and noncontiguous or overlapping intervals. Every one of 508 named F32 arrays must have its exact expected shape and be entirely finite. All 244 declared alias pairs must have byte-for-byte equal uint8 views, including signed zero. No numerical tolerance applies. The reference groups must partition to 264 groups, 34,546,498 conditional factory parameters and 138,185,992 bytes. Serialized storage remains 508 separate disjoint intervals, even if paired values agree.

The root must release actual verification after the separately reviewed downloader reports whole-file integrity. The command requires a root-created JSON release with status `GO_INDEPENDENT_OFFLINE_VERIFICATION` and `artifact` containing `path`, `size_bytes`, and `sha256`; these must match the supplied path and frozen identity. No actual checkpoint values were read during preparation or fixtures. Synthetic fixture files are deliberately small, separately created temporary artifacts.

Runtime: CPU only; 8 GiB address-space hard limit, 120 CPU-second hard limit, measured peak RSS at most 4 GiB, external 180-second wall limit. All socket audit events are rejected. Run with `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1` and an external 180-second process timeout. A mismatch stops with a sanitized reason and no rule change. The output file is created exclusively. There are zero model constructions, forwards, optimizer steps or accuracy claims. Stage 2 loading and parity require a separate source-bound protocol and root authorization.

The synthetic suite covers 33 cases, including successful exact alias equality, signed-zero and one-ULP alias mismatches, NaN/infinities, malformed headers and intervals, and a guard proving a wrong whole SHA stops before the tensor library opens. These tests exercise acceptance boundaries rather than reproducing model behavior.
