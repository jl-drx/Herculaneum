# Root implementation review

The comparison binds actual measured heights and published optical annotations; none of the previous CT/depth adapter inputs is reused. Source labels never enter input normalization or degradation. Optical RGB is used for reference review only. Both qualities share exactly the target grid and support. The4× block mean and bilinear coordinate convention passed a separate SciPy implementation fixture; raw text reconstruction passed a separate NumPy parser. Source full labels passed LFS digests. Tail-based TIFF parsing and the malformed RGB SampleFormat tag are documented, not silently rewritten.

Training uses three physical-parent holdouts, one selected crop each. All samples of the held-out parent are excluded from its training. The paired arms have exactly identical initialization and randomized label/support draws; they differ in height observation quality. Code and protocol were pinned before optimization. The protocol's phrase “seed20261009 per fold” describes the base seed imprecisely: the frozen implementation uses20261009+fold index, yielding20261009,20261010,20261011, each shared by its native/coarse pair. This clarification changes no run, paired comparison or source code. It is not a multi-seed robustness study.

The implementation normalizes each input crop independently without labels. This is a prespecified use of test-input statistics, not a strict training-statistics-only normalization. Nearest-filled values are context only; common targets exclude raw missing observations, invalid4×4 blocks and bilinear neighborhoods touching them. The model can still see nearby filled texture, so the hole-density control is relevant. Common support is not independent chemical truth: annotation-negative means the source annotator did not mark ink, not that chemistry proved its absence.

The small29,937-parameter U-Net and2,048-step CPU budget are a baseline, not a reproduction of the published nnU-Net method. The source configuration specifies a different larger training recipe,250iterations×1,000epochs, with Dice/cross-entropy and SGD. Update counts across these differing models/batches/context sizes are not equivalent compute budgets. Failing the present native control cannot falsify the paper or establish that profilometry lacks ink information.

A post-output sampling audit found that foreground-centered draws and class-weighted BCE both emphasize positives. Its replay uses only the already frozen label/support sequence, no model and no optimizer. The resulting constant-predictor optimum is0.82–0.89, explaining why sigmoid0.5 is not a calibrated natural-prevalence decision. The fixed Dice/Brier metrics are still reported. No threshold or loss was changed, and calibration alone would not improve ranking AP. This is a design limitation to retain, not evidence that a new calibration pass would advance ink detection.

All scientific conclusions are gated by native training fit and training trajectory. Report every parent and both train/test qualities; no pixel bootstrap, post-output region replacement, teacher arm, input-depth recentering, GPU launch or model promotion. No pristine-test claim: all three fields are reference-review exposed, and their planned final predictions become development evidence once inspected.
