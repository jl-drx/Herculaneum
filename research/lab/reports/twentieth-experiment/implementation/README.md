# Phase 20 bounded matched fusion experiment

The runner is prepared for root-authorized execution only. `load_plan(execute=True)` requires the root GO to bind the exact plan, code freeze and scientific protocol. Both historical data and the strict original seed42 checkpoint are read only after that check. No actual scientific execution is performed by the author.

`fusion_adapter.py` is byte-identical to the phase 19 reviewed prototype. Each arm uses its forked-RNG `matched_adapter(20261008)` initialization. The original 34,546,498 unique parameters stay frozen and every original module stays in evaluation mode. The adapter adds 32 feature channels before the original 2D network; that network participates in input differentiation during training.

Training reads the exact phase 18 PHerc0139 schedule and manual targets. Historical pseudo arrays are used only to verify old input/target fingerprints. The unchanged manual smoothed BCE and preservation KL never use them as targets. Before any update, all 32 original batch outputs and all 32 zero-adapter outputs must match the saved seed42 teachers bitwise. Both initialization output arrays are retained. The fusion cache is an ordinary detached FP32 tensor with per-input state, shape, dtype and SHA identities; no inference-mode cache or phase 19 smoke state is imported.

Raw outputs retain one-channel pre/post/fixed-risk logits, exact diagnostic `logits - teacher` arrays and logit gradients. Diagnostic logit differences are not the adapter output. The real 32-channel feature residual, adapted features and decoder-input gradients retain compact SHA, shape and norm receipts. Hidden feature gradients may extend outside manual output support; only output-logit gradients must be exactly zero outside that support. All 5,296 parameters, clipped/unclipped gradients and Adam moments are saved before and after every update. Only final adapter checkpoints are retained.

Each training arm has 32 original full-model calls, 32 depth-fusion calls, 256 original 2D-network calls, 224 adapter forwards, 32 decoder-input backward events, 32 loss backwards and 32 optimizer updates. Full-model events overlap their submodule events. Each final development arm has 150 original full-model and depth-fusion calls, 300 original 2D-network calls and 150 adapter calls, with no backwards or updates. The original model's state, buffers, modes, trainability and absent parameter gradients are checked and retained before/after each worker.

The original tile helper runs under inference mode. The new tile boundary explicitly disables inference mode while retaining `no_grad`, so ordinary fusion caches satisfy the unchanged prototype's tensor contract. Every one of 150 development tile inputs per arm must match its historical normalized-input hash, and a new actual original prediction must match its saved seed42 tile logits bitwise. The fixed six contexts, normalization, sigmoid, Hann weighting and literal cutoff stay unchanged.

The controller launches one worker at a time, polls RSS and aggregate new phase bytes every 0.2 seconds, and kills the process group on an exceeded cap. Each worker additionally has wall, CPU, address-space and file-size limits. Any failed worker produces a preserved STOP with no automatic retry or fallback. Development requires a separate independent PASS that pins the completed training controller result. Passing that numerical barrier does not select arms: both final states and all six contexts are mandatory.

The author fixtures exercise a tiny synthetic model only. They do not load seed42 or scientific arrays and make no accuracy or real-data timing claim. Metadata-only plan preparation likewise does not decode scientific arrays or checkpoints.
