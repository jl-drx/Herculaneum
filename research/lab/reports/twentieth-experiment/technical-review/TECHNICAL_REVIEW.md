The frozen implementation implements the phase 19 matched fusion study and the root phase 20 protocol. No unresolved source issue blocks the bounded CPU experiment. This review authorizes no paid resource, publication or scientific interpretation; root retains execution and scientific decisions. Exact source, protocol, configuration and plan bindings are in `TECHNICAL_GO.json`.

Both branches use the unchanged phase 19 adapter and its forked-RNG factory, with 5,296 parameters and a zero 16-to-32 projection. The actual intervention is an additive feature residual before the original 2D U-Net. Saved one-channel logit differences are diagnostic subtraction, not the adapter architecture. The original fusion stem and all original weights stay frozen; the decoder remains in the autograd graph with respect to its input. The producer records actual decoder-input gradient hook events and compact gradient receipts. Hidden gradients may extend outside manual output support without introducing another loss target.

Before training updates, each arm calls the actual original model on all 32 exact scheduled inputs, captures the original fused feature during that call, checks its original logits bitwise against the cached teacher, then checks all 32 zero-adapter logits and fused-feature identities. Original and zero-adapter output arrays are retained. Fusion caches bind input hash, original state, eval mode, dtype, shape and tensor hash, and are ordinary detached tensors. Cache hashes are rechecked on reuse. Initial and final complete original state, modes, buffers, trainability and absent gradients are compared; source paths keep every original module in eval mode throughout.

The training reader reconstructs only the fixed PHerc0139 schedule with the original normalization, D4 transforms, depth window and manual masks. Historical pseudo arrays participate only in prior combined-input fingerprints and exposure metadata. They are absent from the returned loss targets. The unchanged smoothed BCE plus unit KL uses manual output support; unsupported output-logit gradients must be zero. Only adapter parameters enter AdamW. Every ordered parameter, gradient, clipped gradient and moment is retained before/after each of 32 updates. Fixed risks use every scheduled batch at updates 1, 8, 16 and 32 without choosing an intermediate checkpoint.

The final adapter is compact, finite FP32, reloaded with `weights_only=True` and strict key/shape/dtype/storage/hash checks. There is one final adapter per arm and no duplicate original-model checkpoint. Measurements use no_grad and compare adapter, optimizer, gradient, mode and RNG identities; original state is checked before and after each worker.

Development is gated on an independent numerical PASS bound to the completed training result. Both final branches run all six fixed contexts. Every tile input hash and original seed42 prediction must match its retained reference. The inherited inference helper remains unchanged; a local inference-mode boundary ensures newly captured fused tensors are ordinary while inference still has no gradient. Exact placement, original robust normalization, sigmoid/Hann blending and coverage are preserved. No cutoff fitting or outcome-dependent arm/context selection is present.
