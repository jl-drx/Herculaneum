# Independent NumPy verification plan

Preparation only. No actual new scientific arrays have been evaluated. Root must authorize retained-array reconstruction after the frozen training run completes PASS. This reviewer owns only this new numeric-review directory and will not run models, import Torch, read checkpoints, use network or change earlier evidence.

The independent implementation uses stable log probabilities for epsilon 0.5 smoothed BCE, explicit teacher-to-student Bernoulli KL and destination-to-source indexing for all eight D4 transforms. It recreates manual and pseudo supports separately from pinned acquisition, supervision, validation and seed43 reference masks. The original seed42 teacher logits define preservation targets; the seed43 hard pseudo targets are distinct. FP32 teacher equality is checked through uint32 bit views.

For both fixed arms and every scheduled batch, the checker will reconstruct preupdate and immediate postupdate supported losses, weighted KL and base/full objectives. Their immediate changes are actual same-batch post-minus-pre differences. They are distinct from differences against the initializer and from an online trajectory across changing batches. Saved FP32 worker scalars will be checked using the final plan's unchanged tolerances.

At updates 1, 8, 16 and 32, the checker will reconstruct all 32 fixed schedule batches from saved logits. Each batch independently normalizes manual and pseudo participants before the 32 equal-weight batch risks are averaged. Initializer fixed risk is calculated from the same retained teacher cache, with KL zero. The frozen final gate computes each delta as **final equal-batch mean minus initializer equal-batch mean**, then compares that delta inclusively with -0.0001. It does not rearrange the arithmetic, average per-batch deltas for the gate or add a gate tolerance. Both base and full comparisons must pass. The checker will reconstruct risks independently and also verify the exact gate arithmetic from pinned worker summary floats. Every checkpoint is reported; no best-checkpoint selection is performed.

Further checks will bind array shapes/dtypes, source and batch fingerprints, exact supports/counts, all 64 step records, fixed-risk current-batch agreement with immediate postupdate logits, first-step historical sentinels, and the declared 384 forwards / 64 backwards / 64 updates. Model-state and optimizer-isolation claims will be identified as worker receipts, since this numeric checker will not inspect checkpoints or execute a model. The exact driver schema and final plan pins will be recorded before real retained-array verification.

Synthetic fixtures already cover eight hard-coded D4 rasters, loss decomposition, initializer equality, extreme logits, signed-zero bit patterns, same-batch immediate changes for both arm coefficients, equal-batch averaging that differs from pixel pooling, and five inclusive joint-gate boundary/failure cases. These fixtures exercise numerical semantics without observing new experimental outputs. Conditional retention ranking belongs to a separately frozen stage; it is not inferred from this adaptation-risk audit.
