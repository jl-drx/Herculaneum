# Independent preexecution review: depth-aware residual adaptation

Prepared 2026-10-08 before phase-18 numerical execution or reading new scientific arrays. This review used phase-17 `NEXT_STUDY_DRAFT.md`, phase-13 `RESEARCH_DESIGN.md`, and prior worker/reviewer source text only. Earlier reports and the tracked repository remain immutable. No network requests, checkpoint decoding, model calls, training, or scientific array analysis were performed for this review.

The proposed comparison is interpretable as a bounded development experiment if the exact feature contract and the following controls are frozen first. These recommendations are not execution authorization and do not choose a favorable feature, seed, or result.

## Conditions to freeze

1. **Depth has an index contract, not a verified anatomical sign.** List acquired planes, selected planes, pooling centers, nominal zero, units, sign, dtype, and scaling. Phase 17 identifies published index32 and nominal offsets but does not verify physical zero or inward/outward direction. State that distinction in the model description. Specify every axial difference stencil, boundary rule, divisor, and clipping/normalization operation. Preserve the complete original raw-intensity input to the backbone.
2. **One attributable change.** Freeze one depth-aware residual candidate, one architecture- and parameter-count-matched raw-only residual control, and the unchanged baseline. The control must receive a declared deterministic raw-only mapping with the same tensor dimensions and trainable architecture. Zeroing input channels can leave their weights untrainable; duplicated raw channels create redundancy. Either is a design choice to disclose, not silently call equivalent effective capacity. Do not add geometry, subtractive background correction, per-case depth choices, or learned alignment in this comparison.
3. **Feature and augmentation coordinates.** D4 acts on the last two spatial axes identically for input, hard target, and support masks; it does not reverse depth or its signed coordinate. Show that feature construction commutes with the frozen spatial augmentation where claimed. Boundary finite differences need explicit asymmetric/ramp fixtures. Axial perturbations would invalidate the retained exact teacher/input matching unless a separately frozen compatible teacher contract is supplied; the conservative cached-teacher comparison should retain the exact original depth support and no axial augmentation.
4. **Matched optimization and initialization.** Freeze the adapter architecture, parameter initialization seed, exact initial tensor identity across arms, input scaling, optimizer and its parameter membership, objective, clipping, 32-batch ordered schedule, update count, measurements, and scalar selection gates. Reseed or restore RNG before each arm; arm order must not alter initial tensors or data. Equal parameter count alone does not establish equal trainable behavior. Record zero-gradient groups that follow from the feature ablation.
5. **Cache and exposure identity.** The seed42 preservation teacher is distinct from seed43 hard pseudo-targets. Verify every raw normalized input, manual/pseudo mask and hard target against retained schedule fingerprints before using its teacher row. Verify both historical teacher files are bitwise equal if both are used as evidence. No teacher, label, mask, case identity, or summary statistic may enter feature construction; labels and masks participate only in the declared objective and metrics. Exact PHerc0139 parents/aliases alone are permitted for gradients.
6. **Baseline identity and frozen backbone.** The terminal residual output layer must start at exactly zero and the composed output must reproduce teacher/baseline logits bitwise on the declared checks. Check zero residual, zero preservation KL and drift, and no unintended baseline mutation. Zero initialization means upstream branch gradients are expected to be zero on the first update; require nonzero finite total gradient/update, not every parameter gradient. Require all backbone parameters `requires_grad=False`, no backbone parameters in the optimizer, no backbone gradients, and identical backbone tensor hashes before/after every update or equivalent invariant checks. Hash buffers as well as parameters and reject active dropout, stochastic depth, running-normalization mutation, or mode differences.
7. **Finite and isolated measurements.** Retain pre-update, immediate-post, and fixed-risk outputs at the frozen update numbers, including every unfavorable measurement. Measure under no-grad without changing model mode, optimizer, gradients, or Python/NumPy/Torch RNG. The current fixed-risk batch must equal its immediate-post output bitwise. Reject nonfinite input/features/logits/losses/gradients/parameters and preserve the failed attempt without automatic retry or revised tolerance.
8. **Resource accounting.** Separate frozen-backbone forwards, adapter forwards, teacher forwards, backwards, and updates. If exact cached baseline logits or features replace backbone work during training, require the same reuse in both arms and say that measured costs describe this cache-based adaptation, not whole-model deployment. Include preparation, identity probes, fixed-risk measurements, reload probes, all arms, reviewers, and potential diagnostic inference in the declared envelope. Match training and inference budgets and save actual runtime/RSS/output bytes.
9. **Predeclared interpretation.** Compare both trained arms with the unchanged baseline and with each other; a candidate beating baseline alone does not isolate the value of depth features. Preserve all arm results and use the final state, not the best measured state. Any screen is a computational development criterion, not significance or external validity. Frag4, PHerc0814, and the six already seen phase-16/17 contexts are development evidence. Paris2 cannot provide gradient, calibration, feature selection, depth selection, or a confirmatory claim. Fresh quarantined parent-level confirmation material is currently unavailable; upstream checkpoint/teacher exposure remains a separate qualification.

## Independent saved-output verification contract

The independent checker will use its own NumPy mathematics and indexing, import no author numerical implementation or Torch/model code, decode no checkpoints, and replay no training. Freeze its source and synthetic fixtures before scientific reads. Entry paths must be root-authorized, SHA256-pinned, and linked to the completed protocol/plan, runtime, code freeze, immutable inputs, schedule, and result receipts. It will refuse additional paths or changed arm/update/output schemas.

Save float32 baseline/cache logits and student logits with unambiguous arm/update/batch axes; preferably save adapter residual outputs too, so `student == float32(baseline + residual)` is independently testable. Save exact batch/support fingerprints, feature fingerprints and enough fixed feature recipe metadata for independent reconstruction from authorized retained PHerc0139 arrays. The checker should independently rebuild D4 coordinates, raw normalization and feature channels, compare hashes, and verify input/target/mask support identities without invoking the author's helper.

Recompute separate-support smoothed BCE, hard BCE, teacher-to-student Bernoulli KL, probability drift, declared weighted full/base objectives, equal-batch fixed-risk means, immediate changes, final-minus-initial deltas and every frozen gate. Compare support counts exactly, float32 arrays bitwise where identity is promised, float64 arithmetic under predeclared tolerances, and logged FP32 training losses under a separately declared FP32 tolerance. Use stable log-probability expressions and extreme-logit fixtures; never hide empty support, unknown locations, or class imbalance through pooled support reductions.

Audit logged parameter counts, optimizer membership, gradient/update norms, frozen-backbone hashes, mode/RNG isolation, exact call counts, final-state identity, strict safe reload and resource receipts. These receipts support an implementation audit but cannot be independently proved by retained logits alone; report that limitation instead of claiming full training replay. If checkpoint tensor verification is wanted, it requires a separately authorized non-training decoder outside this checker.

Necessary synthetic fixtures include explicit depth ramp and constant-depth stacks, endpoint stencils, signed coordinate orientation, all eight D4 transforms, feature/D4 commutation, no target/mask dependence of features, zero-residual baseline composition, initial zero KL, extreme logits, disjoint manual/pseudo/unknown supports, unequal support sizes distinguishing equal-batch from pixel-weighted risk, inclusive gate boundaries, corrupted/mismatched hash rejection, and forbidden checkpoint/author-import rejection.
