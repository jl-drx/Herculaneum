# Active Plinius research plan

Updated 12 October 2026 following the user's approval of the
[broader programme](planning/plinius-frontier-programme-20261012/README.md).
This is the active priority order; historical experiment recommendations remain
records of their original decisions. No running protocol is amended by this plan.

## Protected running baseline

Finish the native PHerc0139 nine-fit CPU study with its existing GO, data,
normalization, full depth, stopping, endpoint selection and locked evaluation.
Use its separate read-only verifier after the producer seals all results.
Report the frozen decision and optimization limits unchanged. Its result is one
native annotation-agreement baseline, not a prerequisite for all larger models.

## Independent work now

1. **Correct-sheet recovery:** construct a bounded development intake for surface
   fields, instances and tracing. Separate detector comparisons from tracer
   comparisons. Measure physical coverage and identity mistakes, including tears,
   rather than selecting geometry for a larger ink response.
2. **Strong native learning:** qualify Reader v2 alongside dense-native, Hecate
   and released checkpoint controls. Prepare a paired coverage study with original
   source draws held fixed. Use adequate exposure and an explicit GPU proposal.
3. **Reference and exposure:** extend the physical registry, distinguish local
   exposure from upstream training/teacher exposure, and reserve new support
   using geometry/metadata before inspecting labels or predictions. Build targeted
   correction as a separately controlled data intervention.

Preparation proceeds in this workspace using light CPU/network work. Do not
compete with the live worker using large CPU inference or builds. Use the spare
VM only when hour-scale independent work makes delegation useful; none is assigned
by this plan. Existing public and locally inspected benchmarks are development.

The [first execution packet](in-progress/frontier-intake-20261012/README.md)
contains the completed reference-only topology diagnostic, twelve acquired native
CT contexts, Reader v2 strict CPU qualification, model/source contracts and the
prospective PHerc0175/PHerc1203 whole-family reserve. Geometry reference anchors
and the final training cohort remain next steps; the packet does not authorize
a model comparison or paid launch. Its native CT cohort is not the originally
proposed balanced set of easy/curved/difficult strata.

## Conditional next experiments

- G1: matched surface-field/tracer comparison, then one repair only after its
  failure mechanism is measured.
- I1: matched native-coverage training pair, then multiple paired seeds and new
  physical parents if the pilot is useful.
- A1/J1: targeted reference correction and explicit target-sheet ink projection
  when independently interpretable references exist.
- Acquisition robustness, released representations and efficiency remain ranked
  secondary tracks; local placement/normals are bounded supporting work.

The [experiment cards](planning/plinius-frontier-programme-20261012/PROGRAMME.md)
define provisional success/stop criteria. Freeze each actual cohort, baseline,
implementation and endpoint before execution. The programme is not a claim that
any particular method is novel or that geometry explains PHerc0800's weak maps.

## Closed branches and resource boundary

Carry forward the [negative-evidence ledger](planning/plinius-frontier-programme-20261012/EVIDENCE.md).
No repetition of failed depth/fusion adapters, texture recentering, blind target
depth/origin searches, profilometry continuation or uncertainty averaging already
explained by smoothing without a materially different mechanism and evidence.

New paid compute requires explicit approval of a concrete workload. The first
GPU pilot retains its £10 total cap across retries and attributable overheads;
it is not standing permission to launch. Pin environment/data/models, budget,
artifact delivery and independent shutdown before requesting that approval.
Tiny CPU negatives do not veto adequately designed GPU research.

Research remains primary; prizes are optional. Keep results private and portable
in the existing GitHub repository. No public release or external outreach is
authorized by this plan.
