# Admission conditions for the next supervision audit

Post-result planning note, stored in ordinary private Git alongside the sealed
CT archive. It neither changes that archive nor opens any target values.

The next audit would use all six scorable sites, not select only the visually
closest case. The two source failures remain failures. Native annotations,
teacher predictions and physical ink truth must remain separate claims.

Before acquiring teacher or annotation pixels:

1. Freeze the finite CT-supported alternative set, transfer operator, coverage
   requirements, target-stability tolerance and matched smoothing control.
   NCC differences are not calibrated probabilities. Do not fit geometry to
   target pixels or select alternatives because they produce cleaner letters.
2. Recompute the complete v42 teacher-input tile union for the CT-fit and every
   alternative transfer. The prior footprint screen used the unshifted mapping;
   a shifted query can cross an inference-tile boundary and expand input support.
   Recheck source stencils/extent and all reserved native/reference exclusions
   before treating these enlarged inputs as permissible training information.
3. Verify the particular teacher/annotation files' coordinates and provenance.
   The catalog/source pin alone does not certify historical container/weight
   identity or independent teacher training ancestry. Keep native annotations
   separate from model-generated targets and record coverage failures.
4. Preserve uncertainty about ink-bearing face and nearby interfaces. A stable
   2D teacher map is not a certificate of the correct physical surface. No site
   passed the preceding strict CT pointwise-transfer screen; a conditional
   supervision audit cannot retroactively change that result.

This is preparation for a learning comparison with matched physical coverage
and a simple soft-target baseline. The unchanged nine-fit native study is the
current learning experiment. Do not replace it with repeated searches for a
region that passes the CT screen, and do not open its held-out predictions early.
