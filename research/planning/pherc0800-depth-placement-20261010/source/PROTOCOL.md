# Study52 design: bounded depth placement on retained PHerc0800 data

This protocol is fixed before constructing shifted inputs or running shifted
inference. The current task is design and input/schedule feasibility, with no
new neural-model forwards. A frozen worker and its execution qualification are
still required before launch. Prior study51 evidence must remain unchanged.

## Question and scope

Does moving the input window substantially along the retained render's normal
reveal a repeatable, spatially structured candidate that the nominal window did
not resolve? This is an exploratory target-recovery comparison. It cannot
measure ink accuracy, prove correct wrap placement or distinguish every cause
of an unrecovered signal. Reversal is an input-order control, not a known
negative or an invariance requirement. The sparse M7 audit did not justify
blanket snapping; this test does not snap geometry.

Use segment20251028222030 and the **entire middle row of study51's fixed 3×3
partition**: x512:2048/y1024:1536 (1536×512). This keeps the full horizontal
context and compares three existing review cells together. Selection is by
position in the frozen partition, not by response, darkness, M7 offset or an
apparent character. It is already inspected development material, not a holdout.
Preserve the inherited common support, including any unknown pixels; do not
replace the strip if support or response is disappointing.

Use nominal offsets **d = −15, 0, +15 native layers**. The two nonzero offsets
move the centre by ±129.6 µm, spanning the endpoints of the published recipe's
centre range. They are a three-position screen, not its 31-position sweep.
Intermediate centres and other regions remain untested. These offsets need
not stay within one physical wrap: neighbouring-wrap contamination is an
explicit interpretation risk, not an ink-positive control.

Retain all four previously pinned models (dense_native, seed42, seed43, Hecate),
both plain/padded phases (top40,left200), and both input orders. The design has
48 map views: 16 inherited d0 baseline views and **32 new shifted maps**. No model
is selected for being brighter, darker or more padding-stable in study51. No
training, adapter, ensemble, M7 snap, contrast fit, new CT fetch or GPU is needed.

## Physical inputs and baseline

The unchanged 66-plane render has native index k at signed coordinate k−32.5,
in 8.64 µm units along the rendering normal. Its sign is not an anatomical face
label. Villa receives integer indices25+d through41+d, reversed only after
choosing this same set. Its physical centre is d+0.5 native voxels. Hecate uses
16 linearly interpolated positions32.5+d+(i−7.5)×(9.6/8.64), with the original
global XY resize and quantization. Its physical centre is d. Preserve this
half-voxel difference rather than silently harmonizing the two recipes.

Hecate preparation must use each full global plain/padded canvas, with no local
crop before resize. Reproduce retained d0 inputs byte-for-byte as an execution
control. All shifted positions and their interpolation corners must lie inside
the retained 66 planes; every model context must remain observed. Prove that
prepared nonzero patch occupancy does not alter frozen active cohorts. Unknown
geometry and numerical zero intensity are different concepts.

The comparator is the exact crop of all 16 completed study51 d0 maps. A later
worker must first reconstruct that crop **from saved d0 logits with no new
forwards**, using the original grid, weights, denominator, quantization and
Hecate global output interpolation. Require exact equality on inherited support
for every map. A failure stops launch; no tolerance increase or quiet baseline
replacement is allowed.

Preserve entire original study51 active batch cohorts whenever any tile in the
cohort contributes to the strip. Additional tiles in a retained cohort are
context/batching overhead, not additional scored area. Original global Hecate
four-origin grouping and all denominators remain intact. A reduced crop must
not create a new local grid or regroup batches. Offset-specific receipts bind
depth positions, ordering, prepared input hashes, model and full cohort identity.

## Feasibility and execution gates

Feasibility runs no neural model. Verify retained source/input/model pins;
enumerate contributors under native and Hecate output interpolation; check the
complete inherited support and retained input contexts; reconstruct all d0
prepared Hecate bytes; check shifted-window bounds and cohort occupancy; record
exact cohort lists and a workload estimate derived from measured study51 jobs.
Two independent methods must agree on Hecate interpolation support bounds.

Worker admission is separate: exact d0 saved-logit replay on the strip; shifted
distinct-tile batch-versus-singleton checks with max probability difference
≤1e−5; direct original-framework versus cached accumulation agreement; a
committed-batch interruption/resume check; and fail-closed checks for changed
depth, inputs or cohort. Preserve baseline cohorts for both shifts. Bind the
final source/runtime/input/checkpoint pins before the first production forward.
Save raw logits and receipts atomically after each batch, replay exactly before
map completion, and arrange private checkpoint backup before a long run.

The fixed budget is 32 shifted maps and their declared qualification work.
CPU runtime is forecast from the actual retained cohort counts, not a deadline
or a reason to truncate a map. No automatic GPU fallback. Do not launch this
design merely because the input feasibility report passes.

## Complete review and stopping decision

Review all 48 maps on the same inherited common support, fixed 0–255 display,
both as the full strip and its three predetermined 512-square cells. Brown is
unknown. Report all padding, order and cross-model comparisons at each depth,
plus all three depth pairs for each fixed model/phase/order. Describe responses
with correlation and absolute difference; do not call these accuracy or AP.
Do not choose a depth from mean confidence, brightest pixels, or resemblance
to an expected word. Keep both orders visible; useful evidence need not be
invariant to reversal.

The result that would change the current decision is a coherent stroke group
or recurring text-like structure at a nonzero offset, at the same source
location in both padding phases, with corroboration from both model families
(Villa and Hecate), that was not resolved in d0. This is a **candidate for
independent review**, not authenticated text. Reviewers must also see d0, the
other offset/order, masks and relevant full-depth CT context. Shared training,
texture responses and a neighbouring wrap remain alternatives. A single-family
or padding-specific feature stays a weak lead and does not authorize expansion.

Stop after the predetermined comparisons. If no candidate meets that review
criterion, close this three-position target screen as inconclusive, retain all
outputs and do not launch intermediate depths or move the region to hunt for a
brighter result. The next research priority would return to qualifying the
PHerc0139 paired-acquisition learning benchmark, unless new independent physical
evidence supplies a specific geometry hypothesis. A negative three-position
screen cannot rule out ink or all other depths.

If a candidate passes, the next action is an independent image/geometry review
of the fixed evidence, before proposing a separately frozen depth refinement or
new source acquisition. No automatic model training, pseudo-labels, GPU work,
transcription, prize submission or publication follows from this diagnostic.

Short feasibility work stays in this chat. A spare-VM handoff is useful only if
a later hour-plus local run creates independent work worth delegating. Private
Git commits/pushes are sufficient for this design; no Actions dispatch or PR.
