# Independent native-context geometry contract review

The retained catalog directly links each of the three transformed meshes to its corresponding native rendered array in volume frame `20250728140407`. Render parameters agree on group 0, scale 1, 28 slices, normal flipping, no output rotation or XY flip, no crop, and no additional affine. The attributes confirm slice step 1.0 and the source scan. Thus these three fields are comparable in the same native XYZ coordinates; this does not establish annotation truth or exclude broader tissue dependence.

The exact native renderer is from commit `530584554c031c982ba3aa243e1ea39c4bef9818`. Review identified that the initially copied `d9a472e-QuadSurface.cpp` belongs to the transform source, rather than this rendering revision. The implementer then added the already retained exact `native-QuadSurface.cpp` (SHA-256 `4adeeb75ff144c032efc8db56cee4f2b5778de047fb36f42b717a96458ab0406`). Its surface-center, per-tile scale/offset, float32 bilinear sampling and nearest-normal conventions agree with the staged helper. The old file can remain as provenance, but is not the authoritative render revision.

Independently decoded XYZ TIFFs have matching float32 shapes: w035 `(291,262)`, w039 `(428,386)`, w044 `(302,408)`. With the declared float32 scale 0.05000000074505806, the renderer's canvas arithmetic yields widths/heights `(5240,5820)`, `(7720,8560)`, `(8160,6040)`, respectively. These match native array attributes and `[28,H,W]` array shapes.

The renderer computes `j - 0.5*(28-1)`, giving offsets −13.5 through +13.5. No accumulation is requested; the source default accumulation step is zero. Group 0 and unit slice step introduce no further scale factor in this offset. Normal flipping changes ordering but cannot alter the direction-independent conservative bound.

For any base position b and normal n whose length is at most `1+1e-5`, each represented coordinate obeys `|t*n_i| <= 13.5*(1+1e-5)`. Every floor/ceil trilinear neighbour differs by at most one voxel in each component. Expanding enclosing base extrema by 14.51 therefore leaves `14.51 - 13.5*(1+1e-5) - 1 = 0.009865` native voxels for floating arithmetic. This is far above an individual float32 rounding unit at the supplied coordinate magnitudes (below 10,000). The actual numerical audit must still enclose both prescribed base interpolation alternatives, reject nonfinite/ambiguous geometry, and inspect the actual normal norm extrema. The claim applies to represented source sampling under this release contract, not to unknown physical registration error.

Complete 256×256 input contexts, including 64 pixels around each fixed 128×128 core, must determine the boxes. Neither core-only boxes nor a selected depth subset suffices. A box intersection means possible source-footprint overlap, not proven duplicate tissue. Conversely disjoint conservative boxes exclude common represented input coordinates under this contract but do not establish independent specimens or freedom from model pretraining exposure.

Closed-boundary comparisons are required: equality at a boundary counts as intersection. Every training context intersecting any held-out context must be rejected; invalid training geometry must be rejected separately. An invalid held-out context cannot become an empty disjoint box: all held-out identities remain and the fold must be marked unqualified.

The original protocol misstates the winding count allocation. The preserved erratum correctly uses the mask-frozen CSV identities: w035 109, w039 54, w044 102 (265 total). These counts were independently checked. No IDs or selection rules changed.
