# Independent physical-context audit result

**PASS for the declared native-input geometry exclusion.** This qualifies the conservative physical split calculation; it does not qualify annotation truth, CT availability, acquisition pairing or a learning result.

The separate checker imports no production geometry/helper code. It verified frozen input and mesh hashes, decoded all nine saved coordinate TIFFs, checked the native catalog/render contract, and rebuilt all 265 complete 256×256 base fields and their geometry-validity masks. Its float64 interpolation uses a different arithmetic expression. All masks and qualification decisions agree. Base-extrema disagreement is at most **9.09495e-13 native voxels**; every recorded conservative box equals the union of the two declared base extrema expanded by 14.51.

Every native input retains all 28 depth positions, −13.5 through +13.5. Independently reconstructed double-precision normals were used for an additional endpoint-and-trilinear-neighbour enclosure check, which passed with a minimum remaining margin of **0.0106974 native voxels**. This auxiliary check does not claim bit-exact replay of the C++ normal arithmetic. The direction-independent bounding argument and permitted unit-normal tolerance are documented in `CONTRACT_REVIEW.md`.

All **22,512 cross-winding box comparisons** were independently recomputed using a separating-axis test that treats touching boundaries as intersections. The same **46 possible-overlap pairs** were found, all between w035 and w039. Intersecting axis-aligned boxes are conservative rejections, not proof of actually duplicated CT samples.

Every retained ID, rejected ID, rejection reason, intersecting evaluation-ID list and mask-only supervision total matches. All real contexts are geometry-qualified. The absence of an invalid context in this cohort is not permission to treat invalid geometry as empty or disjoint in later cohorts.

This result should not be reused for a learner with a larger input footprint, a teacher with additional source context, a different renderer or depth support, or whole-winding input normalisation. Any such change needs its own footprint check. Native disjointness also cannot certify teacher-training exposure or biological independence among regions of the same papyrus.

The next admission questions are actual CT support and annotation/paired-teacher validity. This audit removes one concrete leakage concern without solving those separate questions. No label pixels, CT scan chunks, predictions or training were read or generated by the independent geometry check.
