# Matched native CT soft-target learning: implementation and power inventory

Read-only audit, 11 October 2026. Repository commit `cfb5775d4dfc38014b731201ee32712d6a60c2c0`. No model construction, inference, training, network fetch or GPU use occurred in this audit. Recommendations below are not a frozen training protocol.

## Decision

There is no completed equivalent of **real native CT learning from continuous fine-CT teacher targets, with coordinate-corrected soft supervision versus CT-informed target averaging and a matched ordinary smoothing control**. Earlier work tested different teachers, input representations and objectives.

The available engineering is adequate for a bounded CPU baseline. The bottleneck is scientific admission: four 32-square supports in one inspected site are not adequate training coverage or independent evaluation. A teacher-only objective can establish cross-region teacher imitation and optimization behavior. It cannot by itself establish improvement in ink detection or the correctness of an uncertain transfer.

Do not train on these four supports merely to obtain another positive number. Expand the physical data/support contract first, then run a conventional direct full-depth learner with clearly limited claims. Keep the uncertainty treatment separate from source-frame correction and model capacity.

## Earlier soft supervision and neighboring tests

- **Studies8–9:** hard seed43 pseudo targets at threshold 0.5, with a manual-only / pseudo comparison and later 0.25/0.75 label smoothing. These are not continuous fine-acquisition targets. Both used the small historical PHerc0139 adaptation distribution, 32 updates and incomplete reference ancestry.
- **Studies10 and13:** detached original seed42 Bernoulli KL on the same normalized input as the student, alongside smoothed targets. This is a soft preservation regularizer, not extra physical evidence from a better observation. Study13 reduced the overshooting learning rate to 1e-6 and preserved the same small schedule.
- **Studies18,20,21:** rejected small residual/feature/depth adaptations and preservation-allocation designs. Do not revive these under a new name. Study18's two 801-parameter branches modified cached seed42 logits and saw raw-neighbor or explicit-depth features; that is distinct from a standalone raw-CT learner, but its failure also warns against equating tiny-head fit with a viable research model.
- **Study32:** fixed neighboring-depth prediction averaging on Frag6 failed. It is not a training test of soft target averaging. Studies33–36 diagnosed labels, representation and depth ambiguity; no precise optical target alignment was established.
- **Studies37–41:** full 34,546,498-parameter seed42, typically 512 updates of 32 repeated batch-two inputs, learning rate 1e-6, smoothed BCE plus same-input initial-seed42 KL. Study37 added Dice;38/40 expanded coverage;41 removed the new crop's BCE. None trains real coarse CT against a better-acquisition continuous teacher. Their weak transfer does not rule out the new comparison.
- **Studies44–45:** native versus degraded profilometry on separate papyri, conventional small U-Net. No teacher training was run because native fitting never qualified. At 8,192 updates, training APs reached about .552/.590, still materially improving. This remains optimization/representation-inconclusive and cannot be presented as a successful CT learning recipe.
- **Study45 released-checkpoint panel:** seed43 versus42 differs by +.075216 equal-parent Paris AP, with large regional changes. These are descriptive checkpoint differences, not a calibrated noise floor. Matched seed pairs and multiple physical evaluation blocks are needed; doubling one observed difference is not a statistical power calculation.
- **Current supervision audit:** exact teacher-only transfer sensitivity, no training. Hard positive envelopes vary 22–32%; continuous changes are much smaller. It makes an ordinary continuous-target baseline necessary but supplies no trained result.

## Feasible baseline architecture and optimization

A **standalone 28-channel 2D U-Net**, consuming all native planes as channels, is the simplest CPU model that does not reuse the rejected residual/depth-feature adapters. Starting from study44's architecture changes the first convolution from 1 to 28 channels, giving **31,881 parameters** (29,937 + 27×8×3×3). It preserves full depth without handcrafted pooling, a learned surface selector or pretrained checkpoint exposure. It is an ordinary small CT representation baseline, not a proposed frontier model or a released-recipe reproduction.

A stronger conventional width setting can be frozen initially if data coverage warrants it; do not add capacity only after checking final evaluation outcomes. The baseline's ability to fit independent training blocks is a prerequisite for interpreting its negative transfer, not evidence of ink truth. A low-capacity learner's failure cannot exclude information in coarse CT.

Recommended optimization principles for a later actual protocol:

1. Uniform spatial sampling on prospectively defined common valid training support; either ordinary unweighted soft BCE, or explicit importance correction if positive-enriched sampling is necessary. Do not combine foreground-centered sampling with natural-prevalence class weighting as study44 did.
2. Paired initial states, exact patch/augmentation sequences, identical inputs and supports across target arms. No coordinates or teacher-derived masks as model inputs. Use identical normalization learned from training CT only, unless a separately declared transductive input rule is essential.
3. Preserve every raw native plane. No depth recentering, wrap selection, order sweep, extra teacher inference or seed42 preservation term is needed for this initial comparison.
4. Optimize long enough to measure training saturation. A prospective schedule might allow up to 16,384 updates with fixed common measurements and training-only plateau checks, but this number is not a power guarantee. Set the endpoint and learning-rate schedule before data outcomes; if fit is still changing materially at the cap, report budget-inconclusive rather than fail the representation.
5. Use several paired seeds if making a treatment-effect claim. Three is a minimum descriptive replication, not an automatic significance certificate. Preserve all seeds, no best-seed selection.
6. Save model, optimizer, scheduler, exact sampler position and all RNG states atomically at fixed intervals. Strict identity checks must precede resume. Log metric summaries regularly; storing every 28-channel batch is unnecessary if immutable inputs and deterministic schedule can regenerate it.

A convex 28-channel logistic probe would permit a gradient-tolerance optimization certificate and can be a cheap sanity control, but lacks spatial ink structure. It should not replace the conventional baseline or be promoted as the principal research result.

## Power and interpretation blockers

**Physical coverage:** the four checked supports total 4,096 pixels, with only three threshold-informative blocks, inside a single 256-square site. Counting pixels, updates or neighboring tiles as independent experimental replicates would be misleading. The other two available sites are not automatically qualified: their local correspondences failed different checks. Their full-volume CT can aid expanding the data contract, but a target transfer must explicitly retain those failures and unknowns.

**Splits:** use separate physical regions with source-coordinate and mesh/surface provenance, buffer entire model input contexts and normalization supports, and account for winding aliases. Four nearby 32-square masks with 192-square contexts overlap heavily. GroupNorm/InstanceNorm make output depend on spatial patch statistics, so a convolution-only nominal receptive-field calculation is insufficient. Removing evaluation labels from the loss does not remove their CT from training context.

**Target operator:** average continuous transferred teacher values, not thresholded labels, for the baseline comparison. Uniform averaging of CT candidates is a chosen treatment, not posterior marginalization. Candidate means may be shifted as well as smoothed, so the ordinary control must match mean displacement, common support and smoothing footprint. Comparing only to isotropic Gaussian blur leaves geometry versus anisotropy/shift confounded.

**Evaluation reference:** evaluating every student against the same fit-transferred teacher favors imitation of that coordinate convention; evaluating against each arm's own target compares different tasks. Neither tells whether CT-informed averaging improves physical ink accuracy. Use one common evaluation contract and label the result as teacher agreement. A true ink-benefit claim needs independent annotation or another defensible independent reference, or a later separately stated controlled synthetic-registration study with known transform.

**Exposure:** w040 is training tissue and already inspected by this programme. A new frozen region can be prospective with respect to this learner, but not an untouched benchmark for released teachers or the overall research programme. Do not recycle the Paris panel as a new test.

**Depth:** 2D teacher projections at index14 are a coordinate convention. Stability across projected depths10–17 does not identify the true ink-bearing surface or exclude adjacent-wrap contamination. This is not necessarily fatal to a clearly defined paired-volume imitation study, but it blocks precise physical target claims.

**Teacher support:** zero means possible invalid source or uint8 quantization as well as low response. Current eligibility restricts to native-valid and positive teacher support; keep the same eligible set for every arm. Do not let target transformation change which pixels count or silently turn unsupported zeros into negatives.

**Decision:** first produce an admitted, adequately separated common-data/supervision contract. If available support remains just the four small sites, stop before a training claim and preserve the protocol as blocked by data/estimand, not compute. If that contract succeeds, a full-depth conventional CPU comparison is feasible; advance a CT-informed method only after it outperforms both ordinary soft transfer and displacement/support/smoothing-matched controls across paired runs and separate physical evaluation blocks. Improvement in teacher imitation can justify further work, but cannot by itself establish ink accuracy or justify a frontier claim.
